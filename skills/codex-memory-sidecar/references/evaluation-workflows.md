# Evaluation Workflows

Use the bundled command templates when the user wants a repeatable workflow rather than an ad hoc answer.

## Recommended templates

- `commands/memory-recap.md`
  - summarize what the saved memory and current repo state say together
- `commands/memory-audit.md`
  - inspect trustworthiness, provenance, duplicates, stale memory, and auditability
- `commands/memory-release-check.md`
  - run a release-oriented check across docs, plugin packaging, hook/MCP setup, and stored memory state
- `commands/memory-project-recap.md`
  - rebuild the project mental model for context switching

## Verification habit

Treat each template as a workflow skeleton. For important conclusions, always verify them against current files, docs, config, or git history.
